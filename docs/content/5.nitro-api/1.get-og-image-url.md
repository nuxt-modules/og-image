The `getOgImageUrl()`{lang="ts"} Nitro utility builds the absolute OG image URL for a page. Use it in server routes, server middleware, and Nitro plugins. It works without a Nuxt app context.

## Syntax

```ts
function getOgImageUrl(event: H3Event, options?: Partial<OgImageOptions>): string
function getOgImageUrl(event: H3Event, pagePath: string, options?: Partial<OgImageOptions>): string
```

- `event`: The current `H3Event`. It is required. The runtime secret and the origin both come from it.
- `pagePath`: Optional. The page path to build the URL for, for example `/blog/hello`. If you omit it, the current request path is used, without the app `baseURL` and query.
- `options`: The same options as `defineOgImage()`{lang="ts"}, for example `component`, `props`, `extension`.

When a secret is set, the returned URL is a signed dynamic `/_og/d/` URL. The image handler verifies the signature when the image is requested.

The secret can come from `security.secret` at build time, or from `NUXT_OG_IMAGE_SECRET` at runtime. On Cloudflare Workers, the runtime secret is an env binding. Env bindings resolve only through the event, so the event is required.

The origin is the same as the page's `og:image`: your [site URL](/docs/site-config/getting-started/installation), or the request origin if no site URL is set.

## Example

```ts [server/routes/og-image.get.ts]
export default defineEventHandler((event) => {
  const url = getOgImageUrl(event, '/blog/hello', {
    component: 'OgImagePost',
    props: { title: 'My post' },
  })
  return { url }
})
```

If the handler runs on the page request itself, for example in server middleware, you can omit the page path:

```ts [server/middleware/og-image.ts]
export default defineEventHandler((event) => {
  event.context.ogImageUrl = getOgImageUrl(event, { props: { title: 'My page' } })
})
```
