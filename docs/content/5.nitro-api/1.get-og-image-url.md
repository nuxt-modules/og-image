The `getOgImageUrl()`{lang="ts"} Nitro utility builds the OG image URL for a page. Use it in server routes, server middleware, and Nitro plugins. It works without a Nuxt app context.

## Syntax

```ts
function getOgImageUrl(pagePath: string, options?: Partial<OgImageOptions>, event?: H3Event): string
```

- `pagePath`: The page path to build the URL for, for example `/blog/hello`.
- `options`: The same options as `defineOgImage()`{lang="ts"}, for example `component`, `props`, `extension`.
- `event`: An optional `H3Event`. Pass it to get an absolute URL. Without it, you get a root-relative path.

When `security.secret` is set, the returned URL is a signed dynamic `/_og/d/` URL. The image handler verifies the signature when the image is requested.

## Example

```ts [server/routes/og-image.get.ts]
export default defineEventHandler((event) => {
  const url = getOgImageUrl('/blog/hello', {
    component: 'OgImagePost',
    props: { title: 'My post' },
  }, event)
  return { url }
})
```

The `event` argument resolves the origin from the request. Reverse proxy headers like `x-forwarded-host` are respected.

Without an `event`, the URL is root-relative. Useful in contexts with no request, for example Nitro tasks.

```ts
// '/_og/d/p_...'
getOgImageUrl('/blog/hello', { props: { title: 'My post' } })
```

## getOgImagePath()

`getOgImagePath()`{lang="ts"} is also auto-imported in Nitro. It returns the URL path and the template hash.

```ts [server/routes/og-image-path.get.ts]
export default defineEventHandler(() => {
  const { path, hash } = getOgImagePath('/blog/hello')
  return { path, hash }
})
```
