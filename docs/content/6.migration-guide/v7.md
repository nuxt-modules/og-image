## Update @nuxt/fonts

Nuxt OG Image v7 reads fonts through the `fonts:resolved` hook of [@nuxt/fonts](https://fonts.nuxt.com). Update both modules together:

```bash
npx nuxi module add @nuxt/fonts
npx nuxi module add nuxt-og-image
```

If your `@nuxt/fonts` version does not have the hook, OG images use the bundled Inter font. The build then warns:

```
@nuxt/fonts did not report any fonts, so OG images use the bundled Inter font. OG images need a @nuxt/fonts version with the `fonts:resolved` hook.
```

## What Changed

- OG images load the same font files that `@nuxt/fonts` serves, in dev, in prerender, and at runtime. Before v7, fonts from `@nuxt/fonts` v1 failed to load during prerender.
- Builds with webpack or rspack can use every font family and weight. Before v7, they only had the regular weight of `global` families.
- Fonts still need `global: true`. See [Custom Fonts](/docs/og-image/guides/custom-fonts).
